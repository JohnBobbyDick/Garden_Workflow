# Cyber Garden 2026 — Подготовка промпта для Claude Code

## Цель

Разработать полноценную платформу **AI Security Workflow** согласно техническому заданию Cyber Garden 2026 от банка «Центр-инвест».

Перед составлением финального промпта необходимо уточнить все требования к продукту, архитектуре, технологиям, интерфейсу и реализации.

Главное требование: реализовать абсолютно все пункты ТЗ, включая три задачи со звёздочкой и дополнительные технические требования.

## 4. Обязательные ограничения

Claude Code должен соблюдать следующие правила:

- Не использовать готовые workflow-платформы вроде n8n и Node-RED в качестве основы.
- Не использовать Semgrep, Gitleaks, Trivy, detekt с готовыми security-правилами и другие готовые сканеры вместо собственных анализаторов.
- Не использовать LLM для непосредственного обнаружения уязвимостей.
- Не генерировать фиктивные результаты сканирования.
- Не создавать фиктивные интеграции.
- Не оставлять TODO и заглушки вместо требуемого функционала.
- Не считать модуль завершённым без проверки.
- Не нарушать ограничения на сканирование посторонних систем.
- Не раскрывать секреты в логах.

Разрешены собственные эвристики, Regex, парсеры, Kotlin PSI, tree-sitter, библиотеки сравнения версий и справочники уязвимостей.

## 5. Критерий завершения проекта

Проект считается завершённым только тогда, когда:

- Все обязательные функции реализованы.
- Все три задачи со звёздочкой реализованы.
- Дополнительные технические требования реализованы.
- Самописные сканеры действительно обнаруживают проблемы.
- AI корректно обрабатывает результаты сканирования.
- Workflow можно собрать, сохранить и запустить.
- Выполнение workflow отображается в реальном времени.
- Уведомления действительно отправляются.
- CI/CD интеграции действительно работают.
- AI-генерация создаёт валидные сценарии.
- Библиотека шаблонов поддерживает публикацию и копирование.
- Написаны и пройдены автоматические тесты.
- Приложение запускается по документации.

**Главное правило:** Claude Code не должен считать задачу завершённой, пока каждый пункт технического задания не реализован, не проверен и не подтверждён тестами.
