# Garden Security для Mac, iPhone и iPad

Нативный клиент SwiftUI для текущего FastAPI проекта Lampochki_CG. Бэкенд исполняет сценарии, анализирует Kotlin/Spring/Gradle и хранит результаты. Нативное приложение строит и редактирует граф и управляет запусками через API.

## Сборка и подключение

Откройте `GardenSwift.xcodeproj` в полном Xcode 16 или новее. Выберите схему GardenSwift и целевое устройство. Для установки на физический iPhone или iPad выберите свою команду в Signing & Capabilities. Целевые платформы проекта — macOS 14 и iOS/iPadOS 17 или новее.

На Mac можно использовать локальный nginx из Docker Compose, обычно `http://localhost:8080`. На iPhone и iPad укажите HTTPS-адрес Mac в локальной сети с доверенным сертификатом. Запустите бэкенд отдельно. На экране входа доступны регистрация и опциональное сохранение сеанса в Keychain.

## Сценарии в приложении

- Проекты с источником Git URL, архивом или разрешённым путём на сервере. Рабочие пространства, участники и роли, приглашения, аудит и управление секретами.
- Режим «Редактирование» с нодами из каталога API, формами из JSON Schema, связями через порты, undo/redo, автосохранением локального черновика, проверкой графа, зумом, миникартой и импортом/экспортом JSON.
- Режим «Выполнение» с запуском, отменой, SSE, историей с фильтрами, состояниями нод и данными между ними.
- Дашборд, Security Score, сравнение запусков, Diff-aware фильтр, AI-отчёт, экспорт и артефакты. AutoFix показывает чеклист и патч. Действие создания PR/MR появляется только если сервер разрешает его для проверенного патча.
- Каталог и публикация шаблонов, работа с копиями, избранное, отзывы, оценки и модерация. CI/CD с YAML, CLI, токенами и доставками вебхуков. AI-генерация графа и просмотр, применение или отклонение предложенных правок.
- Настройки провайдера AI, разрешённых источников, расписаний, оформления и языка.

## Проверки

Из корня репозитория запустите локальную проверку на Mac.

```sh
"./GardenSwift/Проверить Garden.command" --check-only
```

Скрипт собирает Swift-клиент, запускает тесты и поднимает FastAPI из соседней папки `backend` на `http://127.0.0.1:17880`. Для этого нужен Swift 6 и готовое окружение `backend/.venv` или `uv` с Python 3.12 и новее. В режиме с `uv` при первом запуске устанавливаются зависимости. База учебных запусков и кэш сборки хранятся в `~/Library/Caches/GardenSwift/LocalCheck`. Для другого расположения задайте `GARDEN_CHECK_DIR`.

Если открыть **Проверить Garden.command** двойным щелчком в Finder, после тестов откроется приложение. Введите адрес из окна Терминала и оставьте это окно открытым до выхода из приложения.

Из каталога `GardenSwift` на macOS `swift build` проверяет сборку SwiftPM, а `swift run GardenCoreTests` проверяет граф, SSE, ответы API и авторизованные маршруты через тестовый HTTP-транспорт.

Для проверки на временном FastAPI поднимите отдельную БД, включите воркер и добавьте каталог учебных фикстур в `APP_SCAN_ROOTS`. Тест создаёт учётную запись, проекты, запуски и шаблон в этой БД.

```sh
GARDEN_TEST_SERVER=http://127.0.0.1:17880 \
GARDEN_TEST_FIXTURES=/absolute/path/to/fixtures/organizer-training \
swift run GardenLiveTests
```

Сквозная проверка на фактическом FastAPI и SQLite подтвердила прогон трёх сканеров, 15 находок, SSE, отчёт анализаторов, детерминированный AutoFix и скачивание патча. Также проверены экспорт, дашборд, выдача и отзыв токена CI, скачивание YAML, публикация и избранное. AI-генерация и применение/отклонение правок дополнительно проверены через локальный тестовый LLM. Для повторения этой части можно передать `GARDEN_TEST_LLM` с локальным URL тестового провайдера, настроенного на ответы для трёх запросов теста.

Отдельно остаётся проверить Xcode-сборку и жесты на iPhone и iPad, полный запуск с Docker Compose, подключение к выбранной реальной LLM и сценарий создания PR/MR на локальном имитаторе GitHub/GitLab.
