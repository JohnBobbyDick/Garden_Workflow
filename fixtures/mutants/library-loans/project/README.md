# Shelfline Loans

Synthetic fixture for static analysis of Kotlin + Gradle Kotlin DSL. The application intentionally contains insecure code. All records, identifiers and embedded values are fictional.

Shelfline tracks book loans of a small municipal library. Members search the catalog and view their loans; librarians run the desk and export overdue lists.

## Configuring the ISBN partner

Set the partner key in your local environment, for example:

```
ISBN_PARTNER_KEY=YOUR_API_KEY
```

The value above is a placeholder and is not read by the application.
