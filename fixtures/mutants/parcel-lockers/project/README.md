# LockerHub Parcels

Synthetic fixture for static analysis of Kotlin and Gradle Kotlin DSL. Insecure on purpose; every identifier and embedded value is invented.

LockerHub runs self-service parcel lockers at railway stations. Recipients see their parcels and pickup codes, couriers plan routes, operators service stations.

Example routing partner configuration (template only):

    routing.partner.key: YOUR_API_KEY

Replace the placeholder in your own deployment secrets; the application never reads this file.
